# Проверка сборки для GitHub — 10 ноября 2026

Сборка сравнена с присланным `job-bridge-server-source.zip` (29 файлов). Рабочий QR-вход, управление hh.ru, favicon и шифрованный формат Telegram-сессии сохранены. Исходный снимок сервера не заменяется этой сборкой.

Различия при объединении:

- На сервере подтверждена та же версия CLI с QR-входом. Она включена без изменения сценария авторизации.
- В итог включены ранее подготовленные повторные проверки полномочий перед отправкой, отрицательные тесты HTTP/WebSocket, проверки почты, статические ресурсы и правила Docker build context.
- Версии зависимостей закреплены в lock-файлах; Caddy закреплен на 2.11.8-alpine.
- Исправлен повторный тест `self`: индекс БД исключает Избранное. Старый индекс мигрирует транзакционно; существующие сообщения журнала, настройки и сессии не удаляются. Защита реальных получателей и дневной лимит сохранены.
- В README описаны QR-вход, обязательный HTTPS для hh.ru и тесты текста/PDF в Избранное.
- Исключены временные установщики и резервные копии, обновлены правила Git и SHA256SUMS.

Проверки:

- `python -m unittest discover -s tests -v`: 39 тестов, 37 успешно, 2 браузерных теста пропущены (нужен запускаемый Chromium).
- Проверены миграция индекса с существующей БД, сохранение сессий и журнала, повторные self-тесты и запрет дублей другим получателям.
- Проверены QR-вход, 2FA, обновление QR, прежний вход по коду и сохранение зашифрованной сессии на имитаторах Telegram.
- Отправка текста и PDF через рабочий VPS подтверждена пользователем до формирования этого архива. Новый код миграции индекса пока проверен только локально.
- Docker build и повторное развертывание на VPS в этой среде не выполнялись: Docker недоступен.

Секреты и рабочие данные в пакет не включаются. Это исходники для репозитория, а не резервная копия VPS. Для обновления VPS необходимы существующие `.env`, каталог `secrets` и Docker-томы; они остаются на сервере.

Проверка содержимого пакета:

- Offline-скан detect-secrets 1.5.0 и просмотр исходников: действующих секретов не обнаружено. Единственный кандидат — искусственный пароль в тесте 2FA; проверен как тестовое значение.
- В исходниках не обнаружены пользовательские номер, email и адрес VPS из настройки. `.env`, ключи, базы, сессии, PDF, резервные копии и временные установщики в архив не включены.
- Проверены 10 правил исключения чувствительных и временных файлов через `git check-ignore`.
- Контрольные суммы всех файлов пересчитаны; целостность ZIP и SHA256SUMS проверена.
